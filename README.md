## ⚡ Quick Start

**Clone & jalankan Animal Clinic:**
```bash
git clone https://github.com/<username>/<repo>.git
cd python-oop-projects/animal-clinic
python main.py
```

**Jalankan Singapore Airlines:**
```bash
cd python-oop-projects/singapore-airlines-system
python pemesanan.py
```
